# HotelPro - Output Screenshots Guide

Place the following screenshots in this directory for your evaluation / submission:

1. **`01-login-register.png`**: Login and Registration interface with role selection.
2. **`02-rooms-catalog.png`**: Room listing with category filter (`Standard`, `Deluxe`, `Suite`) and stay date selector.
3. **`03-booking-confirmation.png`**: Successful room booking with price calculation alert.
4. **`04-my-bookings.png`**: Guest "My Bookings" page with **Pay** and **Cancel** buttons.
5. **`05-staff-dashboard.png`**: Staff Dashboard showing all guest bookings with **Check-In** and **Check-Out** action buttons.
6. **`06-admin-panel.png`**: Admin Panel showing the **Add New Room** form and live room inventory table.

*Tip: Press `Win + Shift + S` on Windows to take screenshots and save them into this folder.*
